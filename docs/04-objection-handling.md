# 4. Objection handling

Concede what is true. Reframe to the decision (control plane, not autocomplete). Close on the two-week mart — or a clear no.

Never bash Copilot. Never invent productivity. Never overclaim Origin. If they kill a hypothesis, drop the dependent claim.

---

## How to use this list

Each item: **they say → you concede → you reframe → you close.**  
If the objection is fatal (they only wanted completions; CISO forbids any cloud model; no git on the wedge), do not fight. Take the no.

---

## A. Expand Copilot

### A1. “We’re already in GitHub. Copilot is the native choice.”

**Concede.** True. Lowest change-management. That is the real argument for expanding Copilot.

**Reframe.** Native to the forge is not native to the *incident*. The spine stays GitHub. Year 1 we open PRs on GitHub and let Actions apply. Native does not mean “the agent is allowed to run your SDLC under your envelope.”

**Close.** “If the only requirement is GitHub-native completions, you should expand Copilot. If the requirement is detect → RO investigate → heal in git → human merge, that is a different product. Which requirement is this room in?”

### A2. “Change management will kill a second tool.”

**Concede.** At 6,400 engineers, a second daily driver is a real tax. DevEx is folded; there is no army to train the bank.

**Reframe.** We are not asking the bank to switch. We are asking **one volunteer team** on one mart. Copilot stays everywhere else. The change we care about is the *loop*, not the IDE skin.

**Close.** “If we cannot name one team that will run this for two weeks, we should not start. Can we? NVIDIA and Salesforce already had other AI tools; velocity moved when Cursor became the SDLC control plane, not a second chat window.”

### A3. “Copilot now has agent mode and a coding agent. The gap is closed.”

**Concede.** They shipped it. Treat their usage as the source of truth. Do not pretend those features do not exist.

**Reframe.** If agents are **off**, expanding Copilot is more seats of completions. If agents are **on**, the remaining gap is not “another chat.” It is a **governed, programmable multi-agent loop** you can put on a webhook: specialist order, RO Snowflake, blast-radius, `REPORT.md`, merge-as-approve, CI apply. That is not what you buy when you renew Copilot.

**Close.** “Tell me where agent mode is actually used. If it is already closing mart incidents under a CISO envelope, Cursor is the wrong meeting.”

### A4. “We don’t want two AI tools. We’ll confuse engineers.”

**Concede.** Two IDEs with two agents is a mess. Don’t do that org-wide.

**Reframe.** Design partner = one team, one repo family. Everyone else stays on Copilot. The SDK loop can run without asking the whole bank to change editors.

**Close.** “I will not propose a dual-IDE standard this year. I will propose one pipeline.”

### A5. “Our Copilot metrics look fine — accept rates, seats, satisfaction.”

**Concede.** Those metrics can be real. Completions can be loved.

**Reframe.** They do not appear on the incident ROI slide. Accept rate does not tell you who got paged when `amount` became `order_amount`, or how long to a reviewed PR.

**Close.** “Keep the Copilot dashboard. Add one number: mean hours from break to merged PR on that mart, last quarter vs the two-week trial. If we do not beat it, you expand Copilot. Coinbase dropped accept-rate theatre and measured idea → production; some teams went 20 days to 1.8. I am not importing that number. I am importing the scoreboard — see the case study.”

### A6. “We already did the security review for Copilot. We won’t do another.”

**Concede.** Reviews are expensive. A second vendor is a real CISO cost.

**Reframe.** The review for Cursor is not “may developers see a model.” It is a **narrower envelope**: RO Snowflake, git-only writes, no training on Meridian code (Enterprise privacy path), human merge. We should walk in agreeing with the CISO, not asking them to invent a new category.

**Close.** “Give us a 30-day CISO paper on the envelope, not a new AI category review. If that is still a no, we stop. Box’s security team picked Cursor *for* privacy and agent-quality controls, then measured roadmap, not completions.”

### A7. “Procurement already signed a Copilot enterprise agreement.”

**Concede.** That money is spent or committed. We will not ask you to burn it.

**Reframe.** Sunk cost is not a control plane. A design partner is usage on one team, measured, not a rip-and-replace of the EA.

**Close.** “I’m not here for a Copilot cancellation. I’m here for a two-week number. If it fails, you still have Copilot.”

### A8. “GitHub will just ship this. We’ll wait.”

**Concede.** GitHub will keep shipping agents. That is a rational wait.

**Reframe.** Waiting is a choice to keep editor-plus-GitHub-agents as the control plane, including the **shared failure domain** (17 Aug 2026). You can wait on Origin. You should not wait on a governed loop you can run **locally on the SDK today**, with PRs back to GitHub.

**Close.** “Wait on forge features. Don’t wait on the mart incident. We can run the loop with GitHub as SoT this quarter.”

### A9. “Copilot is cheaper / already in the Microsoft / GitHub bundle.”

**Concede.** Bundle math can win a procurement slide.

**Reframe.** Seat price is not incident price. Unused Copilot seats plus senior pages is the expensive line. Cursor Router (opt-in per group) is how we stop frontier prices on routine turns — conservative **30%** vs pinned Opus-class traffic, not a productivity claim.

**Close.** “Put last quarter’s Copilot spend *and* paged hours on one slide. I’ll put two-week Cursor usage + break-to-merge next to it. Bundle wins if the leak is small.”

### A10. “Assigning issues to Copilot is enough automation.”

**Concede.** For a well-scoped GitHub issue on a greenfield service, that can be useful.

**Reframe.** A schema-drift P1 is not an issue description. It is live catalog vs contract, RO evidence, coordinated specialists, tests, and a deploy gate that is **not** the agent. Issue-to-PR agents still leave apply, Snowflake, and blast-radius as an exercise.

**Close.** “If your coding agent already produces a reviewed dbt PR with tests and never touches Snowflake, show me that and I’ll stand down.”

## B. Lab-led stack (Anthropic / OpenAI)

### B1. “We’ll just use Claude Code / Codex. Best models, less vendor.”

**Concede.** Excellent models. Strong CLI for power users. Direct lab relationship is rational.

**Reframe.** The model is not the SDLC. You will still assemble IDE + CI + policy + routing + audit + forge glue. DevEx is folded. At 6,400 engineers that is a **platform product you do not intend to staff**. Cursor is that product. You can still choose Claude or GPT **inside** it.

**Close.** “Buy the model. Don’t build the control plane. If you have a team funded to build it, I lose — and you should staff it.”

### B2. “We don’t want IDE lock-in. Labs are model-neutral.”

**Concede.** An IDE is a lock-in surface. Cursor is a VS Code-line editor plus a runtime.

**Reframe.** A lab CLI is lock-in to that lab’s meter, eval, and roadmap. Cursor’s lock-in is the **agent runtime and rules** — and it is explicitly multi-model. Copilot’s lock-in is GitHub. Someone will own the control plane. The question is whether you own a kit or a product.

**Close.** “If lock-in is the fear, pick the control plane that can swap models. That’s the opposite of a single-lab stack. Coinbase said the same: any model, Cursor for inference and caching.”

### B3. “We already have ChatGPT Enterprise / Claude Enterprise for the firm.”

**Concede.** Good. Legal already knows those vendors.

**Reframe.** Firm chat is not repo-aware, rule-bound, PR-producing, RO-on-Snowflake automation. Those contracts are **necessary** and **insufficient**. Use them as approved model suppliers behind Cursor.

**Close.** “Keep the firm chat. Don’t confuse it with the engineering control plane.”

### B4. “Quality is what matters. Labs will always be ahead of an IDE company.”

**Concede.** Frontier quality will often live at the labs first. Cursor does not pretend otherwise.

**Reframe.** Quality of a single completion is not quality of a **closed loop**. Meridian’s quality bar is: correct patch, tests green, docs aligned, blast-radius held, human still in the merge. Cursor routes to the frontier model when the turn needs it, and does not pay frontier for every comment rewrite.

**Close.** “Judge us on break → merged PR and test pass, not on a coding-arena screenshot.”

### B5. “We can build the envelope ourselves. We have platform engineers.”

**Concede.** You can. The prototype in front of you is not magic; it is policy plus agents plus CI.

**Reframe.** Building it is the easy week. **Owning it** across languages, incident types, eval, routing, and audit is the year. You folded DevEx. A second internal AI platform is how this dies after a demo.

**Close.** “If you fund that platform, you don’t need us. If you don’t, the kit is a trap. Which is it?”

### B6. “Anthropic / OpenAI will have enterprise agents soon.”

**Concede.** They will keep shipping.

**Reframe.** You would still be assembling a bank SDLC on a lab roadmap. Cursor already has the IDE the staff engineer will actually use, the SDK you can hang a webhook on, and Rules you can check into the repo. “Soon” is how you spend another year of Copilot completions.

**Close.** “We can revisit a lab control plane when it is a product. Today you are choosing a kit.”

### B7. “We want a direct relationship for roadmap and price.”

**Concede.** Direct lab deals can be cheaper at token volume. Relationship matters.

**Reframe.** Cursor does not block a lab relationship. It stops that relationship from becoming your only IDE, only CLI, and only policy engine. Price: Router + usage on the wedge vs raw frontier everywhere.

**Close.** “Keep the lab relationship. Put it behind a router and a merge gate. That’s the Cursor shape.”

## C. Cursor product and company

### C1. “You’re a startup. We’re a bank. Viability?”

**Concede.** Diligence is mandatory. SpaceXAI / Cursor will not be treated like a 20-year core-banking vendor.

**Reframe.** Year 1 we do not become your forge, your warehouse, or your identity provider. We sit on GitHub, we are RO on Snowflake, and a kill switch turns us into investigate-only. Concentration risk you already have: **GitHub + Copilot as one domain**.

**Close.** “Put us through vendor review. Don’t put us in the critical path of apply — CI and humans stay there. That’s the architecture.”

### C2. “Where does our code go? Do you train on it?”

**Concede.** This is a CISO red-line question. It should be.

**Reframe.** Take the **Enterprise privacy / zero-retention / no-training** path. Do not imply a weaker tier. Models may still be third-party (OpenAI, Anthropic, etc.) under their enterprise terms — say that plainly. Hooks and rules keep secrets out of prompts; `dbt_heal/profiles.yml` stays gitignored; no PAT in git.

**Close.** “CISO reviews the envelope and the DPA, not a slide. If training is a rumor in this room, I have already lost.”

### C3. “We need on-prem / air-gapped / no code leaving the bank.”

**Concede.** If that is a hard constraint for the wedge team, Cursor cloud inference may be a no.

**Reframe.** Local SDK runtime, Rules, and git-only writes still matter; some estates can use approved model endpoints. If the wedge is air-gapped COBOL, we are in the wrong first team.

**Close.** “If the data-platform team cannot use an approved cloud model under your DPA, this design partner is the wrong shape. Say that now.”

### C4. “Cursor is just a wrapper on Claude and GPT.”

**Concede.** We call those models. That is a feature.

**Reframe.** The product is the **runtime**: context, rules, hooks, multi-agent order, SDK, Router, Origin, and the editor people will actually live in. A wrapper does not give you investigator-never-edits / healer-never-talks-to-Snowflake.

**Close.** “If you only wanted the model, you would already be done. You asked for SDLC.”

### C5. “JetBrains / Visual Studio / mainframe IDEs — we don’t live in VS Code.”

**Concede.** Large parts of a bank do not.

**Reframe.** Wedge team should be a team that *can* work in Cursor (analytics engineering / modern platform). We do not start in the VS2019 / ISPF estate. SDK loops can still open PRs those teams review in GitHub.

**Close.** “Pick a team that can use the editor, or pick a loop that only uses the SDK. Don’t pick a mainframe IDE bake-off.”

### C6. “What about COBOL and VB6? That’s our real pain.”

**Concede.** It is real pain. It is also the slowest, least instrumented, most change-controlled surface you have.

**Reframe.** An agent that cannot run your compiler, your CICS path, or your CAB calendar will look like a toy. Parking COBOL is how we **protect** that estate from a sloppy trial — and how we protect Cursor from a scorecard it should lose.

**Close.** “Mart first. Bounded legacy spike later. If COBOL is the only yes, the answer this quarter is no.”

### C7. “Origin is competing with GitHub. Our CISO just finished a forge consolidation.”

**Concede.** Forge fatigue is rational. Origin is early beta. A second forge as SoT is a year-1 no.

**Reframe.** Year 1 we **sync**. Pushes land on GitHub. We do not detach 6,400 repos. Origin is a place to read, review, and keep working when GitHub’s AI domain is down — honest limits on merge/Actions.

**Close.** “If Origin sounds like a migration, I misspoke. It is a copy and, later, an optional BCP set. GitHub stays the record.”

### C8. “Origin isn’t full BCP. Why are you talking about the outage?”

**Concede.** On a synced repo, push/merge/Actions still wait. That is not full BCP. Do not overclaim.

**Reframe.** The outage slide is about **failure domains**, not magic continuity. GitHub + Copilot Token Service went down together (Copilot recovered last, ~21:02 UTC on 17 Aug 2026). Cursor local still runs. That is the honest table. Full merge-during-outage is Origin-hosted + dual-homed checks — a later, small set.

**Close.** “I will not sell you BCP you don’t have. I will sell you a second inference domain and a later option.”

### C9. “Usage-based pricing will blow up. Finance will kill it.”

**Concede.** Uncapped frontier traffic will blow up. ~60% of developers pin one expensive daily driver.

**Reframe.** That is why Router exists, **off by default on Enterprise**, on per group. SDK maps P1 → intelligence, else balanced. Conservative story: **30%** vs all-Opus, not 50–60%. Measure token $ on the one repo against a pinned-frontier baseline.

**Close.** “Cap the trial. One org group. If we cannot show the 30% case, finance should kill *expansion*, not the measurement.”

### C10. “Shadow IT. Developers will bring Cursor in anyway.”

**Concede.** They will, if you only offer completions.

**Reframe.** The way you prevent shadow IT is not a ban. It is an **approved control plane** with Rules, SSO, privacy tier, and a kill switch. Expanding Copilot without a programmable envelope does not stop shadow Cursor. It guarantees it.

**Close.** “Sponsor one official design partner or inherit twenty unofficial ones. That’s the VP Eng choice.”

### C11. “This demo is Snowflake + dbt. We’re not a data company.”

**Concede.** The live path is a mart. That is a choice.

**Reframe.** We chose it because it is **bank-shaped**: production data, tests, CISO red lines, git apply. The same spine (detect → RO → heal in git → prove → merge → CI) is how you would do a broken contract test on a payments service. Data is the wedge, not the identity.

**Close.** “If payments is the better first team and they have tests and git, we start there. I used the mart because I can show the envelope without arguing about COBOL.”

### C12. “Agents will ship bad code / hallucinate a drop table.”

**Concede.** Unsupervised agents will. That is why “just let it fix prod” is a no.

**Reframe.** Investigator cannot edit. Healer cannot talk to Snowflake. Blast-radius gate. Dry-run kill switch. Human merge. CI apply. Hallucination is a **review** problem, not a production-write problem.

**Close.** “If we cannot draw that split on a whiteboard to your CISO’s satisfaction, we do not run.”

### C13. “Our monolith is 20 years old. Cursor won’t understand it.”

**Concede.** No agent understands a 20-year monolith on day one. Neither does a new hire.

**Reframe.** Rules, repo-level context, and a blast-radius (“only these modules”) are how you *start*. We still do not pick that monolith as the first design partner unless it has tests.

**Close.** “Monolith is expansion. Mart is proof. Don’t score the trial on the hardest repo you have.”

### C14. “We need this in CI everywhere, not on a laptop.”

**Concede.** A laptop demo is not a platform.

**Reframe.** The SDK is how it leaves the laptop: webhook, watcher, later a runner. Cloud agents are a poor fit until secrets and dbt are injected on a runner you own. We will say that. Local-first is reliability, not the end state.

**Close.** “Two weeks prove the envelope. The next slice is the same orchestrator on a runner — not a new vendor.”

### C15. “Security / SOC2 / PCI / SOX — we’re regulated.”

**Concede.** You are. A coding agent that writes to prod is a finding.

**Reframe.** The architecture is the control: segregation of duties (investigate vs heal vs apply), change in git, human approval, CI as the only apply path, audit trail in `REPORT.md` + PR. That maps to SOX change-management better than a chat sidebar.

**Close.** “Bring Audit to the envelope review. We designed this to be explainable to them.”

### C16. “What if Cursor is down and we’ve moved off Copilot?”

**Concede.** Don’t move off Copilot bank-wide in year 1. Dual-run is the point.

**Reframe.** Apply path never depended on Cursor: humans and Actions deploy. If Cursor is down, you investigate by hand the way you do today. If GitHub is down, Copilot was down with it on 17 Aug.

**Close.** “We are an assist and a loop, not the apply path. That’s why a Cursor outage is not a bank outage.”

## D. Process, politics, and the close

### D1. “We need a bake-off: Copilot vs Cursor vs Claude vs Codex, five teams, 90 days.”

**Concede.** A bake-off feels fair.

**Reframe.** A five-team IDE bake-off will measure completions and vibes. It will not measure break → merge under a CISO envelope. That is how Copilot wins a contest Cursor should not enter, and how COBOL sneaks onto the scorecard.

**Close.** “One team, one mart, two weeks, four numbers: hours, tests, token $, tabletop. If you need a bake-off after that, you’ll have evidence. If you need the bake-off *instead*, we should decline.”

### D2. “Legal / procurement will take six months.”

**Concede.** Banks do that.

**Reframe.** Paper the **design partner** as a scoped trial under the envelope, not as an enterprise standard. Parallel CISO paper. Do not wait for a bank-wide EA to run two weeks on one repo.

**Close.** “What is the smallest paper that lets one team start? I’ll work to that, not to a master agreement.”

### D3. “We have a change freeze / regulatory exam / incident in flight.”

**Concede.** Then this hour should not produce a start date we cannot keep.

**Reframe.** Park the start; keep the envelope review. A freeze is not a no to the control-plane thesis.

**Close.** “Give me the first week the wedge team is allowed to change a mart. I’ll hold the trial to that week.”

### D4. “DevEx is gone / we have no owner.”

**Concede.** Folded DevEx is why a lab kit will fail.

**Reframe.** VP Eng is the owner. CTO is the economic yes. The wedge team lead is the operator. That is enough for two weeks. It is not enough for a bank-wide rollout — and we are not asking for one.

**Close.** “If VP Eng will not sponsor, there is no deal. I’m asking you, not a committee.”

### D5. “Show us more languages / more agents / Bugbot / the full platform.”

**Concede.** The platform is broader than a mart.

**Reframe.** Broader demos make this a product tour. Product tours do not get CISO signatures.

**Close.** “I’ll give you a 60-second menu of the other failure modes. I will not trade the loop for a feature crawl.”

### D6. “This is interesting. Send a proposal.”

**Concede.** They need paper.

**Reframe.** A proposal without a named team, a baseline hours number, and a CISO envelope is a brochure. The close is a design partner, not a PDF.

**Close.** “I will send the envelope and the success criteria tomorrow. I need the team name and the baseline before I write a price.”

### D7. “No.”

**Concede.** A clear no is a good use of the hour.

**Reframe.** Ask which hypothesis died: Copilot already closes incidents; CISO forbids the model path; no wedge team; COBOL-only scorecard; wait-for-GitHub.

**Close.** “Thank you. If the leak is still there in a quarter, the loop will still be here. I will not re-pitch the IDE.”

## F. Line you can use once, then stop

> Copilot is the familiar layer in the editor. Labs are the best models. Cursor is the control plane that can run those models inside *your* SDLC — read-only where it must be, git-only where it writes, human merge before anything applies.
>
> If that is not the problem, expand Copilot. If it is, start with one mart.
